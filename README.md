# Steam (2003) - Deal With Destiny 2 Edition

Классический веб-клиент Valve Steam 2003 года (версия Win32 VGUI2 в оливково-зеленом стиле) с интеграцией модификации **Deal With Destiny 2** от автора **TAZIK29**, издателя **KU.NI**, учетной записью **T1NE** и пасхалками на **TIPRADD**.

Проект полностью оптимизирован для статического хостинга на **GitHub Pages** (работает без необходимости запуска внешнего Python или Node.js сервера).

---

## Быстрый деплой на GitHub Pages (Инструкция)

1. **Создайте репозиторий на GitHub** (например, `steam-2003` или `tazik29-steam`).
2. **Загрузите все файлы проекта в репозиторий**:
   - `index.html`
   - `style.css`
   - `app.js`
   - Папка `assets/` (иконки, капсулы, звуки)
   - `.nojekyll` (необходим для корректной отдачи всех файлов GitHub Pages)
3. **Включите GitHub Pages**:
   - Перейдите в **Settings** (Настройки репозитория) -> **Pages** (в левом меню).
   - В блоке **Build and deployment**:
     - **Source**: `Deploy from a branch`
     - **Branch**: выберите `main` (или `master`), папку `/ (root)`.
     - Нажмите кнопку **Save**.
4. Через 1-2 минуты ваш сайт станет доступен по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

## Возможности и фичи клиента (100% Client-Side)

- **Полная автономность на GitHub Pages**:
  - Все пути к ресурсам являются относительными (`assets/...`), что гарантирует работу как в корне домена, так и во вложенных подкаталогах репозиториев.
  - Автоматическое определение хостинга GitHub Pages: браузерная консоль работает без лишних сетевых ошибок, используя локальную симуляцию мастер-сервера Valve.
- **P2P синхронизация между вкладками (HTML5 BroadcastChannel API)**:
  - При открытии нескольких вкладок или окон сайта они автоматически находят друг друга без сервера!
  - Счетчик друзей динамически обновляется (`Друзья (2 онлайн)`).
  - Сообщения чата передаются в реальном времени между вкладками.
  - Прогресс секретов синхронизируется между окнами.
- **Квест из 10 скрытых секретов**:
  - Интерактивный трекер квеста (`[КВЕСТ: 10 ШАГОВ]`).
  - Финальная награда: Большой рассекреченный архив Valve 2003 (`#window-master-secret`) с лором Deal With Destiny 2 про Оскара Уилсона и поездки на дрезине.
- **Интерактивный ретро-синтезатор звуков (Web Audio API)**:
  - Генерация эмбиент-саундтрека в стиле Half-Life / Kelly Bailey в реальном времени.
  - 12-полосный аудиовизуализатор.
  - Аутентичные звуковые эффекты кликов, открытий окон, активации CD-Key и ошибок.
- **Режим кинескопа (CRT Scanlines & Phosphor Monitor)**:
  - Включение эффекта выпуклого ЭЛТ-монитора 2003 года со сканирующими строками и мягким свечением фосфора.
- **Генератор карточки Steam ID (HTML5 Canvas)**:
  - В меню «Настройки -> Учетная запись» доступна кнопка «Карточка Steam ID...».
  - Генерирует официальный ретро-пропуск T1NE со штрих-кодом Valve, статусом и датой, который можно скачать в формате PNG.
- **Резервное копирование и перенос (JSON Export/Import)**:
  - Экспорт всех найденных секретов, истории чатов и настроек в файл `steam_t1ne_save.json`.
  - Возможность мгновенно восстановить весь прогресс на любом компьютере.
- **Браузер серверов Valve 2003**:
  - Список серверов DWD2, CS 1.6, Half-Life, Day of Defeat, TFC и Roblox TAZIK29.
  - Симуляция колебания пингов и онлайна игроков при нажатии кнопки «Обновить».
  - Копирование команды подключения `connect <ip>` по клику.
- **Диалоги с персонажами (Offline Bot Engine)**:
  - **TAZIK29**: главный разработчик Deal With Destiny 2 (отвечает на вопросы о разработке, движке, поезде и дате релиза).
  - **TIPRADD**: верный зритель, автор нарезок и мемов по стримам Тазика.
  - **KU.NI**: официальное издательство в Steam.

## Горячие клавиши

- `~` (Тильда) — Открыть / скрыть консоль разработчика Valve Source.
- `Shift + Tab` — Внутриигровой оверлей Steam 2003.
- `F12` — Сделать снимок экрана с эффектом вспышки затвора.
